# 3D asset sources for sprites

Goal: realistic, slightly out-of-place Gothic/Victorian furniture and props (think the cross-section dollhouse reference: wallpapered rooms, gilt mirrors, chandeliers, a clawfoot bath, copper pans) rendered from 3D models into 2D sprites that sit inside the vector bouncy castle.

Research date: 2026-11-22. Licences can change, so **re-check each page before downloading**, and skip anything tagged "AI generated" (several 1,000,000-face Sketchfab results looked like AI output).

## Licence rules for this project

| Licence | OK for itch.io? | What we must do |
| --- | --- | --- |
| CC0 (Poly Haven, museum scans) | Yes, commercial too | Nothing (crediting is still polite) |
| CC-BY (most free Sketchfab models) | Yes, commercial too | Credit author + link in the game's credits and the itch.io page |
| CC-BY-NC / NonCommercial | Only if the game stays free forever | Avoid, to keep options open |
| CC-BY-ND / NoDerivatives | No (re-lighting/recolouring a render is a derivative) | Avoid |
| "Royalty free" / marketplace standard licences (BlenderKit, Fab, CGTrader) | Usually yes for rendered sprites | Read the specific licence; never ship the model files themselves |

Keep a `CREDITS.md` with model name, author, link and licence for every asset used.

## Sprite pipeline (Blender, so the sprites stay consistent)

**Implemented** for the nursery: `tools/fetch_polyhaven.py` downloads the models in `tools/sprites.json`, and `tools/render_sprites.py` renders them (see the README). The steps below describe what it does; tune the look in one place at the top of the render script.

1. **Scene template**: one `.blend` with a fixed **orthographic** camera looking straight at the side view (a slight 5 to 10 degree tilt from above helps tops read), transparent film background, and a fixed scale of **1 Blender unit = 100 game units** so sizes stay consistent.
2. **Lighting** (same for every asset): a dim warm key from upper left (candlelight, about 2700K), a cool moonlight rim from behind right, very low ambient. This matches the vignette mood.
3. **Render**: Eevee or Cycles at 2x the in-game size, PNG with alpha. Bake a soft contact shadow (or add it in-game).
4. **Grade** to the castle palette: lower saturation (about -35%) and brightness, slight warm shadows. Do it once in Blender's compositor so every sprite matches.
5. **Export**: trim, keep a fixed pivot at the bottom centre (feet on the floor), name files `room_object.png` (for example `nursery_gothic_bed.png`), and put them in `public/sprites/`.
6. **Hitboxes** stay hand-authored in `level*.ts` (as now); the sprite only replaces the shape drawing in `draw.ts`.
7. Optional: render **several frames** for things that move (chandelier swing, clock pendulum, rocking horse) and load them as a KAPLAY sprite sheet.
